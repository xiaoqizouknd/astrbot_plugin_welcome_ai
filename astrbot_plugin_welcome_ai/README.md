# 欢迎与唤醒词AI

AstrBot 插件：自动生成贴合人格的欢迎新成员文案；支持自定义唤醒词，回复由 AI 微调。
内置一套防风控机制，让机器人回复更像真人、更不容易被平台风控。

## 功能

- **自动欢迎新成员**：群成员加入时 AI 生成欢迎语；短时间连续入群自动**合并成一条**（如"欢迎 A、B、C 加入！"）
- **自定义唤醒词**：命中关键词后发送配置的回复文案，可用 AI 微调
- **回复上下文**：AI 微调时会带上**说话人和原话**，回复更贴合场景
- **回复概率**：每条唤醒词可设 0-100 的概率，避免刷屏
- **频率感知与上限**：命中即记录触发次数并告诉 AI；超过上限插件自动闭嘴
- **主动发言**：机器人自己沉默太久时主动说话，检查间隔随机抖动
- **聊天模式**：只响应唤醒词，或任何消息都回复
- **输出长度限制**：AI 回复不会超长，避免刷屏
- **直连 API / AstrBot provider** 两种接入，API 失败自动重试
- **夜间静默**：设定时段内机器人完全不自动说话

## 安装

1. 把本插件目录放到 `AstrBot/data/plugins/astrbot_plugin_welcome_ai/`
2. 安装依赖：`python -m pip install aiohttp`
3. 重启 AstrBot

## 配置

### AI 配置

| 配置项 | 填什么 |
| --- | --- |
| **API 地址** | `https://api.deepseek.com/v1` |
| **API 密钥** | 你的密钥 |
| **模型名称** | `deepseek-chat` 或 `deepseek-flash` |

**模型温度**：0 表示确定性输出，越大越随机，推荐 0.6 ~ 1.0。

**API 自动重试**：网络错误、429、5xx 会自动重试 2 次（指数退避 0.5s / 1s），
一次性故障不会导致欢迎语或回复丢失。

### 输出长度限制

**配置项：`AI 输出最大长度（字符数）`**

- 默认 120 字，适合群聊
- 0 表示不限制
- 生效范围：欢迎语、唤醒词回复、主动发言、AI 微调，**全都受控**

**两道防线**：

1. **提示 AI**：把“不超过 N 字”拼到提示里，AI 会尽量遵守
2. **兜底截断**：AI 还是超了，直接截断

**截断规则**：

- 尽量在标点处断（句号、问号、感叹号、换行），读起来更自然
- 找不到合适标点，就硬截断并加省略号

**建议值**：

| 场景 | 建议 |
| --- | --- |
| 群聊活跃 | 50 - 80 字 |
| 正常群聊 | 100 - 150 字 |
| 希望 AI 多说点 | 300 - 500 字 |
| 不限制 | 0 |

### 唤醒词

每条唤醒词可以填四个字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| **关键词** | ✅ | 用户消息里出现它就触发（英文不区分大小写，长词优先匹配） |
| **回复文案** | ❌ | 可选 |
| **AI 要求** | ❌ | 可选 |
| **回复概率** | ❌ | 0-100，默认 100 |

**回复概率**：

| 概率值 | 效果 |
| --- | --- |
| `100` | 每次都回 |
| `80` | 大概 8 成的概率回 |
| `30` | 大概 3 成的概率回 |
| `10` | 偶尔回一次 |
| `0` | 从不回（相当于禁用） |

也支持 `80%`（带百分号）、`0.8`（小数写法，0~1 之间按比例换算）。
**注意**：整数一律按百分比理解——`1` 表示 1%，不是 100%。要 100% 填 `100`。

**AI 微调上下文**：启用 AI 微调时，提示词会带上说话人昵称和原话
（如「张三」说：今晚吃什么），AI 的回复会贴合当下场景，而不是干巴巴复读配置文案。

**冷却与概率的先后**：

1. 先掷概率骰子 —— 不命中直接跳过，**不消耗冷却**
2. 冷却未过 —— 也会跳过，**不消耗冷却**
3. 只有真正回复发送成功，才会推进冷却时间戳

所以概率和冷却都不会“空放”，用户实际等待的时间不会白费。

**频率统计与触发上限**：关键词一旦命中就记录（包括被概率或冷却跳过的），
用于给 AI 提供“这是最近 N 秒内第几次触发”的上下文。
如果窗口内触发次数超过「唤醒词窗口内最大触发次数」，插件直接闭嘴不再回复
（0 = 不限制），防止有人在群里刷关键词把机器人刷成复读机。

### 主动发言

| 配置项 | 说明 |
| --- | --- |
| **启用主动发言** | 总开关（改动即时生效，无需重启） |
| **沉默多久后主动发言** | 机器人多久没在这个会话说话就触发 |
| **两次主动发言最短间隔** | 同一个会话两次主动发言之间的最短间隔 |
| **检查间隔** | 后台多久检查一次（实际会随机浮动 ±20%） |
| **只在群聊主动发言** | 私聊不主动说话 |

**沉默计时怎么算**：

- 插件自己发的消息（欢迎语、唤醒词回复、主动发言）会重置计时
- **机器人通过核心 LLM 的回复也会重置计时**（自动识别机器人自身的出站消息）
- 其他插件发送的消息，如果被 AstrBot 识别为机器人自身发出，同样会计入

### 防风控

| 机制 | 说明 | 默认 |
| --- | --- | --- |
| 合并欢迎 | 连续入群合并成一条消息 | 3 秒窗口 |
| 随机回复延迟 | 发送前随机等待，模拟打字 | 0.5~1.5 秒 |
| 最小发送间隔 | 全局和单个会话都遵守 | 0.5 秒 |
| 每分钟回复上限 | 同一会话 60 秒内最多回复 N 条 | 10 条 |
| 触发上限 | 关键词在窗口内触发超限即闭嘴 | 关闭 |
| AI 文案去重 | 最近 6 条内不重复发送相同 AI 文案 | 开启 |
| 夜间静默 | 指定时段完全不自动发言 | 关闭 |
| 忽略自身消息 | 不响应机器人自己发的消息，防止自触发循环 | 自动 |

想要“秒回”体验的话，把随机延迟、发送间隔都调成 0 即可，其他机制不受影响。

### 夜间静默

`夜间静默时段` 填写如 `23:30-07:00`：

- 该时段内：欢迎、唤醒词回复、主动发言、聊天模式**全部静默**
- 跨天时段合法（23:30-07:00）
- 管理员手动执行 `欢迎` 命令**不受影响**
- 留空表示不静默

## 命令

| 命令 | 作用 |
| --- | --- |
| `欢迎 @某人` | 生成一句欢迎语（仅管理员） |
| `欢迎 昵称` | 同上，手动指定昵称（仅管理员） |

## 排错

| 现象 | 处理 |
| --- | --- |
| AI 回复被截断 | 把“AI 输出最大长度”调大，或调成 0 |
| 唤醒词没反应 | 检查概率、冷却、触发上限、关键词 |
| 半夜突然不说话 | 检查“夜间静默时段”是否覆盖了当前时间 |
| 回复变慢 | 随机延迟 / 最小发送间隔调小或设为 0 |
| 同一条消息不再回第二次 | 触发上限或每分钟回复上限生效，按需调大 |
| AI 微调不生效 | 检查 API 地址/密钥/模型名；直连失败会自动重试并回退到固定文案 |
| 主动发言一直不说话 | 检查沉默阈值、主动发言间隔、是否只在群聊生效、是否在静默时段 |

## 数据文件

本插件不写任何数据文件，所有状态都在内存里。
长时间运行时会自动清理超过 24 小时无活动的会话状态，避免内存无界增长。
